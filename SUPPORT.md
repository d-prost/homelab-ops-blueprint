# Support

GitHub Issues are used for reproducible bugs and bounded feature requests.

Useful reports include:

- the smallest reproducible case;
- relevant Docker, Compose, Ansible and OS versions;
- exact non-sensitive error or validation output;
- enough context to identify the affected project boundary.

Hostnames, addresses, credentials, private URLs, secret values, backup identifiers and recovery evidence should stay out of public reports.

This repository is a reference implementation, not an emergency operations service. Production incidents belong in the recovery and support procedures of the environment running the workload.
